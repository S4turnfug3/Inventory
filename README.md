# Vita Inventory

> Professionelles Inventarisierungs- und Dokumentationstool für Homelab- und Server-Infrastrukturen.

## 📖 Über das Projekt

Vita Inventory ist ein modular aufgebautes Python-Projekt zur automatischen Inventarisierung von IT-Infrastrukturen.

Das Ziel ist es, Informationen aus verschiedenen Systemen zentral zu sammeln, zu analysieren und daraus automatisch Dokumentationen zu erzeugen.

Das Projekt wird objektorientiert entwickelt und ist von Anfang an auf Erweiterbarkeit ausgelegt.
